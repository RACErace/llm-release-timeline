收录说明

一条记录代表什么？

一个有日期和出处的公开事件。一个模型可能先发表论文、再推出预览，之后才开放 API 或权重。筛选和标签按各条记录的主要事件归类，同时开放的渠道见条目说明。同日发布的多个规格可能合并在一条记录中。

如何理解日期？

优先采用发布方公告、更新日志、论文首版或官方权重仓库记录的日期。日期沿用来源的记法，特殊时区和分批开放情况见条目说明。只能确定月份或年份时，保留该精度。

热图如何计数？

每格表示一个月内符合当前关键词、机构和事件类型的记录数。颜色由少到多分别代表 0、1、2–3、4–7、8–15、16 条及以上。仅精确到年份的记录列入档案和年度统计。

范围与出处

以原始《LLM 模型发布日期时间线》为起点，补录语言、多模态、推理与代码模型，以及少量架构前史。仅收录已发生且有公开来源的事件，涵盖受限预览。最近一次资料整理日期见页脚。
