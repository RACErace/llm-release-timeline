# 模型年鉴 · 大模型发布年表

一个可检索的中文静态年表。点选热图中的月份可跳到当月记录，也可以按年份、机构和事件类型筛选。筛选条件保存在网址中，可直接分享。[打开年表](https://racerace.github.io/llm-release-timeline/)

## 数据范围

年表以《LLM 模型发布日期时间线》中的 196 个节点为基础，补入其他研究团队、早期模型、地区与语言模型，以及后续的预览、API 和权重开放事件。整理日期为 2026 年 11 月 8 日。[完整数据](./data/releases.json)

每条记录对应一个有来源的公开事件。同一模型在不同日期预览、正式发布或开放权重时可以有多条记录，同日推出的规格可以合并。类型按主要事件标注。日期沿用来源，必要时在说明中标出时区。仅能确定月份或年份的记录保留原有精度。

## 维护

在 `data/releases.json` 中添加一条记录即可更新网页。页面会重新计算年表、筛选项和每月计数。更新全库整理日期时，请同步修改首页的日期与收录说明。

| 字段 | 说明 |
| --- | --- |
| `date` | 事件日期，使用 `YYYY-MM-DD`、`YYYY-MM` 或 `YYYY` |
| `org`、`name` | 机构或团队标识、公开模型名 |
| `kind` | 发布、预览、开放权重、开放 API、受限开放、版本更新、研究公开、公告 |
| `note` | 本次事件对应的模型、范围或开放渠道 |
| `url`、`source` | 原始来源网址和可读标签 |
| `url2`、`stage` | 可选的补充来源和阶段说明 |

优先引用研发团队的公告、开发者日志、官方模型卡或论文。补充现有模型时，请核对同一日期和开放阶段是否已被收录。[提交补充或勘误](https://github.com/RACErace/llm-release-timeline/issues)

## 本地运行

在仓库根目录运行 `python -m http.server 8000`，再打开 [本地预览](http://localhost:8000/)。网页使用原生 HTML、CSS 和 JavaScript，GitHub Pages 直接发布 `main` 分支根目录。
