# 发布来源

来源登记在 `sources.json`。模型仓用于发现公开权重，厂商公告和 API 发布记录用于发现先于权重开放的版本。各来源只产生待核实线索，发布日期和开放方式仍须对照发布方原文。

应用功能、默认模型切换、订阅额度或聊天体验调整不等于模型发布。核实时须找到独立模型版本、API 型号、权重或首次开放的依据；提到模型名不足以收录。已人工确认的应用公告按规范化来源网址排除，规则同时用于来源读取、旧候选重放和新增记录校验，保留该模型其他发布事件。

| 来源 | 读取内容 |
| --- | --- |

| 华为云 MaaS「模型发布公告」 | openPangu / Pangu 的语言模型预置服务；不把其他厂商模型在华为云上架算作华为发布 |

| Agnes AI 官方模型仓 | 完整语言或原生多模态模型权重及发布方模型卡 |
| Google Gemini API 更新日志 | 当前 AI Studio 官方日志；保留完整型号、日期和发布阶段，不把图像、视频、Embedding 或 Decision 专用模型混入语言模型 |
| DeepSeek、xAI、Kimi 官方更新日志 | 完整型号与所在日期区段；区分 Speciale、Exp、Code、Highspeed 等版本，不截取为型号前缀 |
| Inception Labs、MiniMax 官方博客 | 带日期的语言模型发布卡片；过滤获奖文章、客户端功能与音视频生成产品 |
| Mistral API [发布说明](https://docs.mistral.ai/resources/release-notes) | 列表日期与详情中的 API 模型 ID；沿用旧来源进度，不回扫历史，只采集自有语言模型，不采集第三方转售或预告权重 |
| Cohere、Z.ai 官方更新日志 | 自有语言模型及其官方版本；排除检索、嵌入等专用产品 |
| 智谱 AutoClaw 官方模型博客 | 仅补充采集明确写明通过 Coding Plan 开放的新 GLM 模型；不把单纯的 AutoClaw 集成、额度活动或技术介绍算作发布。不代替智谱技术博客或 API 更新日志 |
| Xiaomi MiMo、LongCat 官方更新日志 | 模型仓之前的 API 发布、预览与正式版本 |
| 火山方舟「模型发布公告」 | 只采集字节跳动自有语言模型。公告只精确到月份时保留月份，不从页面修改时间或模型 ID 推算发布日期 |

原百炼标题读取器的 `bailian` 标识已由 `bailian-releases` 替代。新的日期识别首次运行会建立历史基线，只检查最近三天的公告，避免把多年旧条目重新投递。旧投递回执继续保留。

Hugging Face / ModelScope 优先检查底座关系、任务类型和完整权重文件。模型卡中的原生训练精度与事后量化导出分别判断。模型仓名称、发布方和自有架构相符，且正文明确发布完整模型权重时，可以进入核实队列；这些信息本身不证明模型从零预训练。跨发布方底座改造、适配器和量化重包仍过滤。

Hugging Face 的仓库最后修改时间只用于发现线索，不作为权重发布时间。自动采集要求仓库在扫描窗口内创建、已观察到受限权重转为公开，或可验证窗口之前的仓库版本尚无符合条件的权重文件。README、聊天模板或其他元数据改动不会单独触发候选。无法读取公开历史且没有其他时序证据的旧仓库不自动投递，仍可根据发布方公告核对或手工补查。ModelScope 沿用原有逻辑。

RSS/Atom 优先读取正文，避免把媒体图片的同名 `description` 字段当作发布摘要；识别标准 Atom 文章链接和 XHTML 正文。证据指纹使用完整条目、日期和阶段，不截取前 180 字。Anthropic、Meta 的专用解析也保留同一链接下的型号、日期或阶段变化。型号匹配统一处理 Unicode 连字符。已有的 Vertex RSS 作为历史补充来源保留，当前 Google API 发布由 AI Studio 更新日志覆盖。

模型仓来源只覆盖权重，不代表已经覆盖该厂商的 API。登记新厂商时应同时核对其官网发布记录和 API 更新日志；不存在可稳定读取的发布页时，应明确保留这个覆盖限制，不能用模型仓代替。

事件去重只使用解析器明确给出的完整模型名；无法完整识别时，保留原始证据标识，不猜测型号前缀。日期和发布阶段参与去重，同一公告内的不同型号保持独立；同日同型号的概括性发布消息可匹配已核实的 API 上线记录。预览、权重开放、之后的 API 上线仍分别处理。只有月份的同名版本更新还保留正文指纹，避免一个月内多次更新互相覆盖。

更换来源解析规则时，通过 `revision` 和 `bootstrap_days` 进行一次有范围的重查；本次订阅和文档修复重查最近十四天，Meta 保持原有一天窗口。历史基线、已收录记录和投递回执保留。之后的相同快照与进程重启不会重复入队，未来日期的公告留到其发布日期再处理。

没有预期发布表、声明有日期的页面缺少日期、正文结构变化、HTTP 故障或验证页均视为读取失败，不用空结果覆盖已保存进度。讯飞接口页的公告没有发布日期，只作为待核实线索，不推算日期。模型库分页先检查整页，再判断是否走出时间窗口，避免页内时间戳交错时漏掉新条目。新增来源时应同时测试正常发布、无关条目、重复回放和读取失败，再手动运行采集检查生产结果。
